# Agent rules and instructions

> ⚠️ **MANDATORY**: These rules MUST be followed in every interaction. No exceptions.

## Git

- NEVER commit, push files unless explicitly told by user. This applies to every single commit and push — ask for explicit confirmation each time, even if permission was given earlier in the conversation.
- NEVER delete branches unless explicitly told by user.
- Do NOT use conventional commit prefixes (e.g., `feat:`, `docs:`, `fix:`) in commit messages unless the user explicitly requests them.
- Commit messages MUST start with a capitalized word (e.g., "Add", "Update", "Remove" — not "add", "update", "remove").

## OpenCode docs

- ALWAYS search https://opencode.ai/docs/ when the user asks about any OpenCode features or configuration.
